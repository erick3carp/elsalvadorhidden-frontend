# El Salvador Hidden

El Salvador Hidden is a full-stack cloud travel platform built with Next.js and Microsoft Azure.

The platform helps travelers discover authentic destinations across El Salvador, explore places by interest and region, save favorites, create itineraries, and eventually receive personalized travel recommendations.

## Live Website

https://www.elsalvadorhidden.com

## Current Features

- Responsive travel website
- Destination listing
- Destination pages
- About page
- Contact page
- AI trip planner interface
- Azure Static Web Apps deployment
- Custom domain and HTTPS
- GitHub Actions CI/CD
- GitHub Codespaces development environment
